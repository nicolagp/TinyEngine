# TinyEngine

An educational project for learning:

- C++ concurrency
- Thread pools and work queues
- HTTP server fundamentals
- LLM inference server setup

## Goals

1. Build a small concurrent server from first principles.
2. Understand how requests move through a queue and worker pool.
3. Add a simple mock model before connecting a real inference runtime.
4. Measure latency, throughput, and resource usage.

## Possible milestones

- Thread-pool experiment
- Minimal HTTP health endpoint
- Mock completion endpoint
- Request queue and backpressure
- Local model runtime integration
- Basic benchmarks
